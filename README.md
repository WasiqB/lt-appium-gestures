# lt-appium-gestures

This is the sample project for Appium gestures using TestMu AI (formerly LambdaTest).

## Prerequisites

- Java Development Kit (JDK) v17 or higher
- Maven
- An IDE like IntelliJ IDEA or Eclipse
- An active TestMu AI account
- Appium server and drivers installed
- Mobile device or emulator/simulator
